# Lesson 00: The maths toolkit

> What maths does machine learning actually use, and what does it *mean*?

**Status:** Not started

Work through [`lesson.ipynb`](lesson.ipynb). Each idea gets written as plain Python (loops only, no NumPy) in [`toolkit.py`](toolkit.py), checked by [`test_toolkit.py`](test_toolkit.py):

```bash
uv run pytest lessons/00-maths-toolkit
```

**Ideas:** reading notation as code, mean, variance and standard deviation, functions, derivatives as "nudge and see", partial derivatives and the gradient, the chain rule, the dot product, matrices and shapes, exponentials and logs.

**Starting point:** GCSE maths. Nothing else assumed.
